# Gallery 图文笔记与足迹

Gallery 已接入原有静态构建和 GitHub Pages 流程，不需要数据库、地图 Key 或额外的 Python 依赖。

## 新增一篇笔记

复制现有笔记文件夹，例如 `files/gallery/kyoto-riverside/`，把文件夹改成唯一名称，例如 `Orion` 或 `hangzhou-weekend`。目录名支持英文字母（大小写均可）、数字和连字符，生成的页面地址保留原始大小写。编辑 `main.md` 并替换 `images/` 内的图片。一个文件夹对应一篇笔记，自动扫描 `files/gallery/*/main.md`，不用维护列表。

```yaml
---
title: 湖边的一天
date: 2026-10-24
place:
  name: 杭州 · 西湖
  country: CN
  lat: 30.2431
  lng: 120.1500
---

在这里写 Markdown 正文，可以使用标题、引用、列表、链接和正文图片。
```

- 元数据只保留 `title`、`date`、`place` 三项，均必填。卡片摘要自动从正文提取，不再填写 `summary`、`tags`、`cover`、`images`、`example` 或 `draft`。
- `date` 使用 `YYYY-MM-DD`，表示拍摄或到访日期，决定卡片排序与地图连线顺序。同一天的记录按文件夹名排序。
- `place.lat` 是纬度（−90 到 90）；`place.lng` 是经度（−180 到 180）。使用 **WGS84**，不要直接混用高德／腾讯的 GCJ-02 或百度的 BD-09 坐标。
- `place.name` 是地点名称，`place.country` 是两个大写字母的国家／地区码，如 `CN`（中国）、`JP`（日本）。分类根据实际笔记自动生成“全部”和各个国家，无需维护国家列表。
- 相册自动读取笔记文件夹内的 `images/`；若没有此目录，则读取 `main.md` 同目录的图片。只扫描所选目录的直接子文件，不递归，忽略隐藏文件和非图片文件。
- 图片按文件名自然升序显示，如 `1.jpg`、`2.jpg`、`10.jpg`，忽略字母大小写；第一张自动作为封面。推荐命名 `01.jpg`、`02.jpg`，通过改名调整顺序。至少放入一张图片，支持 JPG、JPEG、PNG、WebP、GIF、AVIF、SVG。
- 图片说明自动使用“笔记标题 · 图 N”。相册图片无需在正文重复；正文仍支持 Markdown 图片语法。
- 两篇内置笔记为虚构示例，4 张 SVG 为示例插画，说明放在正文中。发布真实笔记时替换正文与图片即可。
- 暂不展示的笔记可放在以 `.` 开头的文件夹中；删除笔记或隐藏文件夹后，下次构建会清理该笔记已生成的阅读页。

双击 `preview.cmd` 即可预览，保存 Markdown 后自动刷新。已有环境也可运行：

```powershell
.venv/Scripts/python.exe scripts/build.py
```

## 页面与交互

- 足迹地图位于整个笔记列表上方，横向占满栏目；“显示连线”和“定位足迹”并排放在地图标题旁。
- 下方瀑布流卡片展示封面、图数、标题、正文摘要、日期和地点，按新到旧排序；宽屏三列，手机两列，数量少或筛选后也不拉伸卡片。单卡最大宽度 360px；封面保留图片原始比例、不裁切，最大高度 480px，超长图片等比缩小。标题最多两行、摘要最多三行（手机两行）。
- “全部／各个国家”、年份、文字搜索联动卡片和地图点位。搜索覆盖标题、正文、地点及国家名称。
- 地图直接跟随国家分类：“全部”显示世界，选择国家后按底图中的该国边界显示完整范围。即使搜索结果为空，也保留该国家视野；底图未收录的小国家则按该国所有笔记坐标定位。仍支持拖动、缩放和「定位足迹」。
- 世界总览使用 1:1.1 亿底图；国家视图按需加载 1:1000 万的海岸线、国界和省份／州／都道府县等一级行政区边界，并支持更近的缩放。边界线与国家轮廓打包在同一个文件内，当前页面内缓存；加载失败保留总览底图，重新选择国家可重试。
- 当前筛选结果按旧到新连线；连线仅代表记录先后，不是实际道路、航线或完整行程。可关闭连线。
- 点击卡片或地图点打开图文阅读弹窗；Esc 或关闭按钮退出。弹窗和独立阅读页的相册一次显示一张图片，通过左右按钮、底部圆点、键盘方向键或手机横向滑动手动切换，右上角显示页码，不自动轮播。点击图片打开原图；仅一张图片时隐藏切换控件。关闭 JavaScript 后仍能横向滚动浏览相册。
- 同一个经纬度的多篇笔记合并为可选择的点位，避免互相遮挡。
- 每篇也有独立地址 `gallery/<文件夹名>/index.html`，便于分享；禁用 JavaScript 仍能查看卡片和阅读完整笔记。
- 空集合、没有搜索结果、底图加载失败、阅读预览加载失败均提供对应提示或替代入口。

## 实现位置

| 文件 | 用途 |
| --- | --- |
| `scripts/gallery.py` | 扫描与校验元数据、复用现有 Markdown 渲染、生成卡片和阅读页 |
| `assets/css/gallery.css` | Gallery 专属样式、手机布局、深浅色主题 |
| `assets/js/gallery.js` | 筛选、阅读弹窗、地图、足迹连线 |
| `assets/js/gallery-carousel.js` | 弹窗与独立阅读页共用的单图相册、手动切换与页码 |
| `assets/maps/world.geojson` | 本地 Natural Earth 低分辨率世界底图 |
| `assets/maps/countries/` | 按国家拆分的本地 Natural Earth 1:1000 万底图 |
| `scripts/prepare_gallery_maps.py` | 从下载的原始 GeoJSON 重新生成国家底图，不在日常构建时执行 |
| `assets/vendor/leaflet/` | 本地 Leaflet 1.9.4 和许可证 |

国家视图和世界视图使用不同精度的地理底图，国家视图包含数据源收录的一级行政区边界，不提供街道导航或更下级的市县边界。地图数据来源和许可见 `assets/maps/README.md`。日常浏览完全使用本站资源；请通过本地 HTTP 预览或 GitHub Pages 访问，浏览器直接打开 `file://` 文件会限制地图和弹窗的 fetch 请求。

不要直接修改 `gallery/` 中的生成 HTML。旧的 `content/site.json` 中 `gallery` 数组不再用于该栏目。
