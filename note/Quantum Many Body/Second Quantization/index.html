二次量子化本质是极致的线性代数

波函数的语言说到底虽然也是希尔伯特空间的矢量语言，但做得还不够彻底。把连续的函数表象变成进一步离散的粒子数表象，此即二次量子化。

首先把所有包含不同粒子数的波函数 Ψ(r1,r2,r3,…)\Psi(\mathbf{r}_1,\mathbf{r}_2,\mathbf{r}_3,\ldots)Ψ(r1​,r2​,r3​,…) 统统打包到一个空间，也即Fock空间

HF=H0⊕H1⊕⋯⊕HN\mathcal H_F = \mathcal H_0\oplus\mathcal H_1\oplus\cdots\oplus\mathcal H_NHF​=H0​⊕H1​⊕⋯⊕HN​

注意到所有的单粒子波函数可以用某一正交完备本征基底 {ϕi(r)}\{\phi_i(\mathbf r)\}{ϕi​(r)} 展开，而多粒子波函数又可以由单粒子基底的直积张成的基底展开（记得归一化，或者说归 NNN 化？）

∣Ψ⟩=∑i1,…,iNCi1⋯iN∣ϕi1⟩⊗⋯⊗∣ϕiN⟩|\Psi\rangle = \sum_{i_1,\ldots,i_N} C_{i_1\cdots i_N} |\phi_{i_1}\rangle\otimes\cdots\otimes|\phi_{i_N}\rangle∣Ψ⟩=i1​,…,iN​∑​Ci1​⋯iN​​∣ϕi1​​⟩⊗⋯⊗∣ϕiN​​⟩

于是想到干嘛不干脆把 NNN 粒子的直积基底写成粒子数占据的形式

∣n1,n2,n3,…⟩|n_1,n_2,n_3,\ldots\rangle∣n1​,n2​,n3​,…⟩
∣Ψ⟩=∑{ni}C{ni}∣n1,n2,…⟩|\Psi\rangle = \sum_{\{n_i\}} C_{\{n_i\}} |n_1,n_2,\ldots\rangle∣Ψ⟩={ni​}∑​C{ni​}​∣n1​,n2​,…⟩

满足 ∑ni=N\sum n_i = N∑ni​=N

ん？什么波函数，你看这哪里有波函数啊，这不是纯纯的矢量吗

不过这么搞有一点点的不严谨，因为实际符合全同粒子对称性/反对称性的空间要比理论上的张量积空间更小。我们需要把基底投影到对应的对称/反对称空间

HN±=P±(N)H1⊗N\mathcal H_N^\pm = P_\pm^{(N)}\mathcal H_1^{\otimes N}HN±​=P±(N)​H1⊗N​
F±=⨁N=0∞HN±\mathcal F_\pm = \bigoplus_{N=0}^{\infty}\mathcal H_N^\pmF±​=N=0⨁∞​HN±​

P±(N)P_\pm^{(N)}P±(N)​ 是对称/反对称投影算符

更进一步，要改就改得彻底一点，作用在波函数上的算符那一套也可以扔掉，换成人民群众喜闻乐见的矩阵。由于现在一套粒子数表象就可以完全描述一个态，所以我们对态的操作就变成了纯粹的对粒子数的操作，为此引入产生算符 a^†\hat a^\daggera^† 和湮灭算符 a^\hat aa^

以归一化的 NNN 粒子态 ∣ΨN⟩∈HN±|\Psi_N\rangle\in\mathcal H_N^\pm∣ΨN​⟩∈HN±​ 为例，我们希望向这个系统中加入一个处于 ∣f⟩|f\rangle∣f⟩ 的粒子。直观的想法是构造张量积 ∣f⟩⊗∣ΨN⟩|f\rangle\otimes|\Psi_N\rangle∣f⟩⊗∣ΨN​⟩，但这个态未必满足全同粒子的交换对称性。为此产生算符可以定义成以下形式

a^±†(f)∣ΨN⟩=N+1 P±(N+1)(∣f⟩⊗∣ΨN⟩)\hat a_\pm^\dagger(f)|\Psi_N\rangle = \sqrt{N+1}\, P_\pm^{(N+1)} \left(|f\rangle\otimes|\Psi_N\rangle\right)a^±†​(f)∣ΨN​⟩=N+1​P±(N+1)​(∣f⟩⊗∣ΨN​⟩)

N+1\sqrt{N+1}N+1​ 用来补偿整体对称化投影的系数

湮灭算符就定义为其 Hermitian 共轭

a^±(f)=[a^±†(f)]†\hat a_\pm(f) = \left[\hat a_\pm^\dagger(f)\right]^\daggera^±​(f)=[a^±†​(f)]†

在这种定义下，玻色子和费米子的正则对易关系可得

[A,B]=AB−BA[A,B] = AB-BA[A,B]=AB−BA

Fermion

{c^i,c^j†}=δij,{c^i,c^j}=0,{c^i†,c^j†}=0\{\hat c_i,\hat c_j^\dagger\} = \delta_{ij},\qquad \{\hat c_i,\hat c_j\} = 0,\qquad \{\hat c_i^\dagger,\hat c_j^\dagger\} = 0{c^i​,c^j†​}=δij​,{c^i​,c^j​}=0,{c^i†​,c^j†​}=0

干脆定义

n^=a^†a^\hat n = \hat a^\dagger\hat an^=a^†a^

作为粒子数算符，显然的，这个矩阵的本征态就是Fock空间的本征基底。

有了产生湮灭算符，所有波函数表象下的算符都可转化为粒子数表象下的矩阵，事实上这件事在波函数的视角下也是经常干的，考虑第一量子化中的单粒子算符 h^\hat hh^，引入单粒子矩阵元

直接有

算符 ∣ϕi⟩⟨ϕj∣|\phi_i\rangle\langle\phi_j|∣ϕi​⟩⟨ϕj​∣ 的作用等效地可以视作波函数中单粒子波函数成分的跃迁 ∣ϕj⟩⟶∣ϕi⟩|\phi_j\rangle\longrightarrow|\phi_i\rangle∣ϕj​⟩⟶∣ϕi​⟩，如果展开的基底就是二次量子化选取的基底，那么在粒子数表象中等效有

A^=∑ijhija^i†a^j\hat A = \sum_{ij} h_{ij}\hat a_i^\dagger\hat a_jA^=ij∑​hij​a^i†​a^j​

例如单粒子的Hamiltonian，动能算符

如果选择动量本征态作为单粒子基底，就得到

其中又有

于是二次量子化下有

另外，虽然会显得有些闲的没事干，但我们可以反过来用离散的本征态反过来表示连续的位置基底，写出倒反天罡的转换
