1 / 欧式路径积分

我们知道实时间作用量和传播子

SM[x]=∫dt[m2(dxdt)2−V(x)]S_M[x] = \int dt \left[ \frac m2\left(\frac{dx}{dt}\right)^2 -V(x) \right]SM​[x]=∫dt[2m​(dtdx​)2−V(x)]
KM=∫Dx eiSM[x]/ℏK_M = \int\mathcal Dx\, e^{iS_M[x]/\hbar}KM​=∫DxeiSM​[x]/ℏ

Wick转动令t=−iτt=-i\taut=−iτ，得到

SM=∫(−i dτ)[−m2(dxdτ)2−V(x)]=i∫dτ[m2(dxdτ)2+V(x)]\begin{aligned} S_M &= \int(-i\,d\tau) \left[ -\frac m2\left(\frac{dx}{d\tau}\right)^2 -V(x) \right]\\ &= i\int d\tau \left[ \frac m2\left(\frac{dx}{d\tau}\right)^2 +V(x) \right] \end{aligned}SM​​=∫(−idτ)[−2m​(dτdx​)2−V(x)]=i∫dτ[2m​(dτdx​)2+V(x)]​
SE[x]=∫dτ[m2(dxdτ)2+V(x)]S_E[x] = \int d\tau \left[ \frac m2\left(\frac{dx}{d\tau}\right)^2 +V(x) \right]SE​[x]=∫dτ[2m​(dτdx​)2+V(x)]
SM=iSES_M=iS_ESM​=iSE​

由此定义欧式路径积分

eiSM/ℏ=e−SE/ℏe^{iS_M/\hbar} = e^{-S_E/\hbar}eiSM​/ℏ=e−SE​/ℏ
KE(xf,τ;xi,0)=∫x(0)=xix(τ)=xfDx e−SE[x]/ℏK_E(x_f,\tau;x_i,0) = \int_{x(0)=x_i}^{x(\tau)=x_f} \mathcal Dx\, e^{-S_E[x]/\hbar}KE​(xf​,τ;xi​,0)=∫x(0)=xi​x(τ)=xf​​Dxe−SE​[x]/ℏ

求解这个积分后再进行代换即变成实时间的路径积分。

2 / 二次型的精确求解

我们知道路径积分大部分都是没办法严格求解的，不过二次型是个例外，这一点用有限维积分很好解释，考虑积分

I=∫RNdNx exp⁡(−12xTAx)I=\int_{\mathbb R^N}d^Nx\, \exp\left(-\frac12x^TAx\right)I=∫RN​dNxexp(−21​xTAx)

进行对角化分解

A=OTΛOA=O^T\Lambda OA=OTΛO
Λ=diag⁡(λ1,…,λN)\Lambda=\operatorname{diag}(\lambda_1,\ldots,\lambda_N)Λ=diag(λ1​,…,λN​)

做正交变量变换 y=Oxy=Oxy=Ox，于是

I=∏i=1N∫−∞∞dyi e−λiyi2/2I=\prod_{i=1}^N \int_{-\infty}^{\infty}dy_i\, e^{-\lambda_i y_i^2/2}I=i=1∏N​∫−∞∞​dyi​e−λi​yi2​/2
∫dyi e−λiyi2/2=2πλi\int dy_i\,e^{-\lambda_i y_i^2/2} = \sqrt{\frac{2\pi}{\lambda_i}}∫dyi​e−λi​yi2​/2=λi​2π​​
I=(2π)N/2det⁡AI=\frac{(2\pi)^{N/2}}{\sqrt{\det A}}I=detA​(2π)N/2​

现在开始推广到路径积分。对于欧式路径积分

Z=∫Dϕ e−SE[ϕ]/ℏZ=\int\mathcal D\phi\,e^{-S_E[\phi]/\hbar}Z=∫Dϕe−SE​[ϕ]/ℏ

我们这里先把作用量写成最原始的推导过程中的离散形式，这有助于我们找到一个对应方式，以谐振子为例，时间切分 ϵ=TN+1\epsilon=\frac{T}{N+1}ϵ=N+1T​ 下的离散作用量为

SE,N=m2ϵ∑j=0N(qj+1−qj)2+mω2ϵ2∑j=1Nqj2S_{E,N} = \frac{m}{2\epsilon} \sum_{j=0}^{N}(q_{j+1}-q_j)^2 + \frac{m\omega^2\epsilon}{2} \sum_{j=1}^{N}q_j^2SE,N​=2ϵm​j=0∑N​(qj+1​−qj​)2+2mω2ϵ​j=1∑N​qj2​

转化为二次形式

SE,N=m2ϵ[(2+ω2ϵ2)∑j=1Nqj2−2∑j=1N−1qjqj+1]S_{E,N} = \frac{m}{2\epsilon} \left[ (2+\omega^2\epsilon^2)\sum_{j=1}^Nq_j^2 - 2\sum_{j=1}^{N-1}q_jq_{j+1} \right]SE,N​=2ϵm​[(2+ω2ϵ2)j=1∑N​qj2​−2j=1∑N−1​qj​qj+1​]

其对应着矩阵

KN=mϵ(2+ω2ϵ2−10⋯0−12+ω2ϵ2−1⋯00−12+ω2ϵ2⋱⋮⋮⋮⋱⋱−100⋯−12+ω2ϵ2)K_N= \frac m\epsilon \begin{pmatrix} 2+\omega^2\epsilon^2&-1&0&\cdots&0\\ -1&2+\omega^2\epsilon^2&-1&\cdots&0\\ 0&-1&2+\omega^2\epsilon^2&\ddots&\vdots\\ \vdots&\vdots&\ddots&\ddots&-1\\ 0&0&\cdots&-1&2+\omega^2\epsilon^2 \end{pmatrix}KN​=ϵm​​2+ω2ϵ2−10⋮0​−12+ω2ϵ2−1⋮0​0−12+ω2ϵ2⋱⋯​⋯⋯⋱⋱−1​00⋮−12+ω2ϵ2​​
SE,N=12qTKNqS_{E,N}=\frac12\mathbf q^TK_N\mathbf qSE,N​=21​qTKN​q
AN=KNℏA_N=\frac{K_N}{\hbar}AN​=ℏKN​​
∫RNdNq e−SE,N/ℏ=∫RNdNq e−12qTANq\int_{\mathbb R^N}d^Nq\, e^{-S_{E,N}/\hbar} = \int_{\mathbb R^N}d^Nq\, e^{-\frac12\mathbf q^TA_N\mathbf q}∫RN​dNqe−SE,N​/ℏ=∫RN​dNqe−21​qTAN​q

所以整个问题严格可解。

KE(xf,T;xi,0)=mω2πℏsinh⁡ωT×exp⁡[−mω2ℏsinh⁡ωT((xf2+xi2)cosh⁡ωT−2xixf)]K_E(x_f,T;x_i,0) ={} \sqrt{\frac{m\omega}{2\pi\hbar\sinh\omega T}} \times\exp\left[ -\frac{m\omega}{2\hbar\sinh\omega T} \left( (x_f^2+x_i^2)\cosh\omega T-2x_ix_f \right) \right]KE​(xf​,T;xi​,0)=2πℏsinhωTmω​​×exp[−2ℏsinhωTmω​((xf2​+xi2​)coshωT−2xi​xf​)]

事实上离散矩阵 KNK_NKN​ 对应于连续的微分算符

K^=−md2dτ2+mω2\hat K = -m\frac{d^2}{d\tau^2}+m\omega^2K^=−mdτ2d2​+mω2
12qTKNq→N→∞12∫0Tdτ q(τ)K^q(τ)\frac12\mathbf q^TK_N\mathbf q \xrightarrow{N\to\infty} \frac12\int_0^Td\tau\,q(\tau)\hat Kq(\tau)21​qTKN​qN→∞​21​∫0T​dτq(τ)K^q(τ)

之前自己一直认为路径积分有滥用符号的嫌疑，把本应该是离散形式的积分变量都塞到了作用量中。现在看完全可以换个视角，把一整条路径视作高维空间的一个点，作用量视作定义在这个点上的函数，如此看反而更符合自己的数学直觉。强行去思考“路径”的积分总容易令人误解。

3 / 路径积分视角下的本征态

尽管由上述方式我们求得了谐振子的严格传播子，但这不意味着我们可以直接得到与波函数理论一样的本征函数与本征能级。

En=ℏω(n+12),n=0,1,2,…E_n=\hbar\omega\left(n+\frac12\right), \qquad n=0,1,2,\ldotsEn​=ℏω(n+21​),n=0,1,2,…

为了从传播子得到量子化，引入正则配分函数

Z(β)=Tr⁡e−βHZ(\beta)=\operatorname{Tr}e^{-\beta H}Z(β)=Tre−βH

由谱分解，如果哈密顿量能够量子化，那么应该有能量本征基底下的

Z(β)=∑ne−βEnZ(\beta)=\sum_ne^{-\beta E_n}Z(β)=n∑​e−βEn​

另一方面，注意到位置本征基底下

Z(β)=∫−∞∞dx ⟨x∣e−HT/ℏ∣x⟩=∫−∞∞dx KE(x,βℏ;x,0)Z(\beta) = \int_{-\infty}^{\infty}dx\, \langle x|e^{-HT/\hbar}|x\rangle = \int_{-\infty}^{\infty}dx\, K_E(x,\beta\hbar;x,0)Z(β)=∫−∞∞​dx⟨x∣e−HT/ℏ∣x⟩=∫−∞∞​dxKE​(x,βℏ;x,0)
T=βℏT=\beta\hbarT=βℏ

相当于对所有首尾相接的路径积分，也就是周期欧氏路径积分

Z(β)=∫x(0)=x(βℏ)Dx e−SE[x]/ℏZ(\beta) = \int_{x(0)=x(\beta\hbar)} \mathcal Dx\,e^{-S_E[x]/\hbar}Z(β)=∫x(0)=x(βℏ)​Dxe−SE​[x]/ℏ

就拿刚刚解出来的谐振子当例子，我们可以严格求解整个配分函数

Scl(x,x;T)=mωx2tanh⁡(ωT2)S_{\mathrm{cl}}(x,x;T) = m\omega x^2\tanh\left(\frac{\omega T}{2}\right)Scl​(x,x;T)=mωx2tanh(2ωT​)
KE(x,T;x,0)=mω2πℏsinh⁡(ωT)exp⁡[−mωx2ℏtanh⁡(ωT2)]K_E(x,T;x,0) = \sqrt{\frac{m\omega}{2\pi\hbar\sinh(\omega T)}} \exp\left[ -\frac{m\omega x^2}{\hbar} \tanh\left(\frac{\omega T}{2}\right) \right]KE​(x,T;x,0)=2πℏsinh(ωT)mω​​exp[−ℏmωx2​tanh(2ωT​)]
Z(β)=mω2πℏsinh⁡(ωT)×∫−∞∞dx exp⁡[−mωℏtanh⁡(ωT2)x2]Z(\beta) ={} \sqrt{\frac{m\omega}{2\pi\hbar\sinh(\omega T)}} \times \int_{-\infty}^{\infty}dx\, \exp\left[ -\frac{m\omega}{\hbar} \tanh\left(\frac{\omega T}{2}\right)x^2 \right]Z(β)=2πℏsinh(ωT)mω​​×∫−∞∞​dxexp[−ℏmω​tanh(2ωT​)x2]
Z(β)=12sinh⁡(ωT)tanh⁡(ωT/2)Z(\beta)= \sqrt{ \frac{1}{ 2\sinh(\omega T)\tanh(\omega T/2) } }Z(β)=2sinh(ωT)tanh(ωT/2)1​​
Z(β)=12sinh⁡(βℏω/2)Z(\beta)= \frac1{2\sinh(\beta\hbar\omega/2)}Z(β)=2sinh(βℏω/2)1​

利用级数展开，成功导出能级

Z(β)=e−βℏω/2∑n=0∞e−nβℏω=∑n=0∞e−βℏω(n+1/2)Z(\beta) = e^{-\beta\hbar\omega/2} \sum_{n=0}^{\infty}e^{-n\beta\hbar\omega} = \sum_{n=0}^{\infty} e^{-\beta\hbar\omega(n+1/2)}Z(β)=e−βℏω/2n=0∑∞​e−nβℏω=n=0∑∞​e−βℏω(n+1/2)
En=ℏω(n+12),n=0,1,2,…E_n=\hbar\omega\left(n+\frac12\right), \qquad n=0,1,2,\ldotsEn​=ℏω(n+21​),n=0,1,2,…

类似的我们会试着去求一下本征波函数，其实注意到

∫dxa K(xb,T;xa,0)ψn(xa)=e−iEnT/ℏψn(xb).\int dx_a\, K(x_b,T;x_a,0)\psi_n(x_a) = e^{-iE_nT/\hbar}\psi_n(x_b).∫dxa​K(xb​,T;xa​,0)ψn​(xa​)=e−iEn​T/ℏψn​(xb​).

这说明 ψn(x)\psi_n(x)ψn​(x) 其实是传播核 KKK 的一个本征函数。换个形式写成谱分解

K(xb,tb;xa,ta)=∑n⟨xb∣n⟩e−iEnT/ℏ⟨n∣xa⟩.K(x_b,t_b;x_a,t_a) = \sum_n \langle x_b|n\rangle e^{-iE_nT/\hbar} \langle n|x_a\rangle.K(xb​,tb​;xa​,ta​)=n∑​⟨xb​∣n⟩e−iEn​T/ℏ⟨n∣xa​⟩.
K(xb,xa;T)=∑nψn(xb)ψn∗(xa)e−iEnT/ℏ.K(x_b,x_a;T) = \sum_n \psi_n(x_b) \psi_n^*(x_a) e^{-iE_nT/\hbar}.K(xb​,xa​;T)=n∑​ψn​(xb​)ψn∗​(xa​)e−iEn​T/ℏ.

可以对时间做 Fourier 变换，定义Green 函数

GE(xb,xa)=1iℏ∫0∞dT ei(E+i0)T/ℏK(xb,xa;T).G_E(x_b,x_a) = \frac{1}{i\hbar} \int_0^\infty dT\, e^{i(E+i0)T/\hbar} K(x_b,x_a;T).GE​(xb​,xa​)=iℏ1​∫0∞​dTei(E+i0)T/ℏK(xb​,xa​;T).
GE=∑nψn(xb)ψn∗(xa)1E−En+i0.G_E = \sum_n \psi_n(x_b)\psi_n^*(x_a) \frac{1}{E-E_n+i0}.GE​=n∑​ψn​(xb​)ψn∗​(xa​)E−En​+i01​.
GE(xb,xa)=∑nψn(xb)ψn∗(xa)E−En+i0.G_E(x_b,x_a) = \sum_n \frac{ \psi_n(x_b)\psi_n^*(x_a) }{ E-E_n+i0 }.GE​(xb​,xa​)=n∑​E−En​+i0ψn​(xb​)ψn∗​(xa​)​.

当 E→EnE\to E_nE→En​ ，Green 函数出现极点，而极点的留数正比于 ψn(xb)ψn∗(xa).\psi_n(x_b)\psi_n^*(x_a).ψn​(xb​)ψn∗​(xa​).

所以从路径积分传播子做能量变换以后，定态波函数可由此提取出来。欧式积分的方法其实也可以做，不过用到路径积分求解波函数的情形毕竟还是少数，这里不多写。
